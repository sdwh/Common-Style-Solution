3. Flow Comparison: Static vs. Relative vs. Absolute

Static: Normal flow, does not accept top/left. Relative: Moved visually, but retains original space in flow. Absolute: Completely removed from normal flow.

Position | static

Width decider in normal flow 🙄

Position | Relative (top: 15px; left: -25px)

Shifted visually, flow space preserved.

Position | Absolute (bottom: -20px; right: 20px)

Removed from flow, anchored to nearest positioned parent.

4. The Classic Absolute Centering Trick

How to center any element inside a container with absolute positioning using transform: translate(-50%, -50%).

Dead Centered
top: 50%; left: 50%; transform: translate(-50%, -50%);
.center-item {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}

6. Z-Index & Stacking Context

z-index controls the third dimension (depth). It only works on elements with a specified position (relative, absolute, fixed, or sticky) or flex/grid items.

z-index: 1
Red (Bottom)
z-index: 2
Green (Middle)
z-index: 3
Blue (Top) 
.red   { position: absolute; z-index: 1; }
.green { position: absolute; z-index: 2; }
.blue  { position: absolute; z-index: 3; } /* On top of red & green */
