Icons & OpenMoji Guide

Styling SVGs with CSS, currentColor Magic & OpenMoji Library Integration

1. SVG Styling with CSS & currentColor Magic

By setting stroke: currentColor; or fill: currentColor; inside inline SVGs, the icon automatically inherits whatever font color is applied to its parent element — including on :hover states! 

/* SVG automatically adapts to hover text color */
svg {
    stroke: currentColor;
    fill: none;
    transition: transform 0.2s, stroke 0.2s;
}
button:hover {
    color: teal; /* Both text AND icon turn teal instantly! */
}
