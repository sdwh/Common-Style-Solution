2. 3D Card Flip (Hover to Reveal)

Using perspective: 1000px;, transform-style: preserve-3d;, and backface-visibility: hidden; to build a realistic 3D flipping card.

Front Side
Mystery Joker
Hover me to flip →
Back Side
Superhero Unlocked!
180° Y-Axis Rotation 
.card-container { perspective: 1000px; }
.card-inner     { transform-style: preserve-3d; transition: transform 0.7s; }
.card-container:hover .card-inner { transform: rotateY(180deg); }
.front, .back   { backface-visibility: hidden; position: absolute; }
.back           { transform: rotateY(180deg); }
