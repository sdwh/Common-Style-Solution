The Ultimate 2-Dimensional Layout System: Columns, Rows, Areas & Responsive Patterns

1. The Magic Auto-Fit Grid (Zero Media Queries!)

Every web developer's favorite trick: repeat(auto-fit, minmax(160px, 1fr)) creates a completely responsive grid of cards that wraps automatically at any screen size!

#1 Robot
#2 Ninja
#3 Superhero
#4 Mage
#5 Crystal
#6 Element 
.magic-grid {
    display: grid;
    /* Automatically creates as many columns as fit (min 160px, max 1fr) */
    grid-template-columns: repeat(auto-fit, minmax(160px, 1fr));
    gap: 16px;
}
💡 auto-fit vs auto-fill: auto-fit stretches the existing cards across the full width if there is empty room. auto-fill reserves empty column tracks for future elements without stretching existing cards.

3. Semantic Layouts with grid-template-areas

Design complete application layouts visually in code using ASCII-like named areas.

Dashboard Header | Modern App Bar
Sidebar
  • Overview
  • Analytics
  • Settings
Main Content Area

The main view automatically fills the remaining horizontal and vertical space allotted by the grid track template.

Notification Widget: System is operating normally.
© Common Style Solution Grid System 
.dashboard {
    display: grid;
    grid-template-areas:
        "header  header header"
        "sidebar main   main"
        "sidebar widget widget"
        "footer  footer footer";
    grid-template-columns: 180px 1fr 1fr;
    gap: 12px;
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.widget  { grid-area: widget; }
.footer  { grid-area: footer; }

4. The 1-Line Center: place-items: center

Shorthand for align-items: center and justify-items: center combined. It centers elements in both axes with a single property!

Centered in 1 line!
display: grid; place-items: center; 
.container {
    display: grid;
    place-items: center; /* Centers both horizontally & vertically! */
    height: 180px;
}
