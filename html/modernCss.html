2. Sibling Hover Dimming using :has()

Hover over any card below. Notice how all other cards dim smoothly, focusing attention on the active element — achieved purely in CSS without JS mouse event handlers!

Fast
Precious
Dynamic
Powerful
/* When container has a hovered child, dim all other children */
.container:has(.item:hover) .item:not(:hover) {
    opacity: 0.35;
    transform: scale(0.95);
}
.item:hover {
    transform: scale(1.05);
}

5. Modern Architecture: Nesting, @layer & @scope (#9, #10, #12)

Modern CSS supports native nesting without preprocessors, cascade layers (@layer) for controlling specificity wars, and scoped styles (@scope).

Native CSS Nesting

No Sass/Less required! & syntax works natively in evergreen browsers.

@layer & @scope Architecture

@layer components { .btn { ... } } guarantees priority order regardless of selector weight. @scope (.card) to (.content) creates donut scopes that don't leak styles! 

/* Native CSS Nesting */
.card {
    background: #f8fafc;
    & .btn {
        background: teal;
        &:hover { background: darkcyan; }
    }
}

/* Cascade Layers & Scoped Styles */
@layer reset, base, components, utilities;
@scope (.card) to (.card-body) { p { color: #475569; } }
