3. Modern Pseudo-Classes: The :has() Parent Selector

:has() enables styling an ancestor or previous element based on the state of its descendants!

When you check this box, notice how the parent card container changes its border color, background tint, and elevation automatically via :has()!

nth-child(even) Styling:
  • #1 (first)
  • #2 (even)
  • #3 (odd)
  • #4 (even)
  • #5 (last)
/* Styles the parent card whenever a checked checkbox exists inside it! */
.card:has(input[type="checkbox"]:checked) {
    border-color: #008080;
    background-color: #f0fdfa;
    box-shadow: 0 4px 12px rgba(0, 128, 128, 0.15);
}
